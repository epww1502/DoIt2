# DoIt2 기획서

지금 앱(0.3.0, 2026-11-23)에 들어 있는 것을 기준으로 정리했다. 기능을 더하거나 규칙을 바꾸면 이 문서도 같이 고친다.

## 1. 한 줄 소개

연인, 친구, 가족과 함께 쓰는 버킷리스트 + 기록 앱.
가고 싶은 곳과 해보고 싶은 것을 한 공간에 같이 담고, "오늘 뭐 하지?"는 뽑기로 정하고, 해낸 뒤에는 사진과 별점, 한 줄 후기로 남긴다.

## 2. 누구를 위한 앱인가

| 사람      | 하고 싶은 것                                                    |
| --------- | --------------------------------------------------------------- |
| 연인      | 데이트 코스와 가고 싶은 맛집을 모아 두고, 다녀온 곳을 추억으로  |
| 친구 모임 | 같이 갈 곳을 모으고, 되는 날을 맞추고, 누가 뭘 하고 싶은지 보기 |
| 가족      | 주말에 할 것, 여행지 목록                                       |
| 혼자      | 개인 버킷리스트와 기록 (나만 보는 공간)                         |

## 3. 지키는 원칙

- **가입 없이 바로**: 이메일이나 전화번호 없이 익명 계정으로 시작한다. 기기를 바꿀 때는 계정 코드(12자리)로 옮긴다.
- **'공간'을 몰라도 되게**: 첫 화면은 "누구와 쓸지"만 묻고, 공간 이름과 아이콘은 정해 둔 값으로 만든다.
- **같이 고쳐도 안 사라지게**: 목록을 통째로 덮어쓰지 않고 변경 단위로 보낸다. 오프라인에서는 쌓아 뒀다가 보낸다.
- **광고 없음, 무료**.
- **AI는 누를 때만**: 처음 쓸 때 외부 AI로 글이 간다는 것을 알리고 동의를 받는다.
- **필요한 것만 모으기**: 기능 사용·오류 기록에 담은 항목 이름이나 쓴 글은 넣지 않는다.

## 4. 화면 구조

아래 탭 4개와, 그 위에 열리는 화면들.

| 탭   | 화면                      | 하는 일                                                                         |
| ---- | ------------------------- | ------------------------------------------------------------------------------- |
| 목록 | `app/(tabs)/index.tsx`    | 버킷리스트. 가보기(탐방)·해보기(도전), 카테고리, 보기 방식 바꾸기               |
| 일지 | `app/(tabs)/done.tsx`     | 함께한 기록. 사진 크게 / 간단히 보기, 지도·사진·통계·한 해 돌아보기로 가는 입구 |
| 추천 | `app/(tabs)/pick.tsx`     | 오늘 뭐 하지? 뽑기 + 날씨                                                       |
| 설정 | `app/(tabs)/settings.tsx` | 공간, 프로필, 알림, 테마, 앱 아이콘, 도움말, 휴지통, AI 사용량                  |

그 밖의 화면

- 항목: 담기·수정(`item/new`), 상세(`item/[id]`), 장소 검색(`item/search-place`), 할 것 코스 지도(`item/course`), AI로 채우기·추천(`item/ai`), 다시 담기(`item/redo`), 가져오기(`item/import`), 공유받은 목록(`item/shared`)
- 기록: 남기기·수정(`record/[id]`), 공유 카드(`share/[id]`), 사진 크게 보기(`photo`)
- 일지: 지도(`done/map`), 사진 모음(`done/photos`), 통계(`done/stats`), 한 해 돌아보기(`done/year`), 웹 링크로 공유(`done/share-web`)
- 공간: 관리(`space`), 만들기(`space/new`), 들어가기(`space/join`), 내 공간 목록(`space/list`), 멤버(`space/member`), 공간 프로필(`space/profile`)
- 계정: 내 프로필·계정 코드(`profile`), 계정 되찾기(`account/restore`)
- 그 밖에: 처음 화면(`welcome`), 다가오는 날(`upcoming`), 알림함(`notifications`), 휴지통(`trash`), 도움말(`help`), 문의하기(`inquiry`), 앱 아이콘(`app-icon`), 고잇투 일정 담기(`import/goit`)
- 관리자 (PIN으로 열기): 현황(`admin`), 받은 문의(`inquiries`), 로그(`admin-logs`)

## 5. 기능

### 5.1 공간

- 한 공간에 최대 10명. 한 사람이 여러 공간에 들어갈 수 있고, 보이는 순서를 바꿀 수 있다.
- 초대: 6자리 초대 코드나 초대 링크. 링크를 누르면 앱이 열리고 코드가 채워져 있다.
- 공간장: 이름·아이콘을 바꾸고, 공간장을 넘길 수 있다.
- 공간마다 다른 닉네임·사진을 쓰거나 나를 숨길 수 있다.
- 혼자 쓰는 개인 공간도 만들 수 있다.
- 신고와 차단: 사용자 콘텐츠를 신고하고 사람을 차단할 수 있다. 신고는 운영자가 24시간 안에 처리한다.

### 5.2 버킷리스트 항목

- 종류 두 가지: **가보기(탐방 📍)**와 **해보기(도전 ✨)**. 카테고리(맛집, 카페, 여행, 요리, 운동 등)와 실내·실외를 붙인다.
- 장소: 카카오 장소 검색이나 지도로 고른다. 카카오맵·네이버 지도·구글 지도로 바로 연다.
- 할 것 체크리스트: 여러 명이 동시에 체크해도 둘 다 남는다. 위치가 있는 할 것은 코스 지도에서 번호 핀으로 잇는다.
- 참고 링크 최대 5개 (미리보기 카드), 사진 최대 3장, 예상 비용.
- 하고 싶어요: 누가 하고 싶어 하는지 표시한다. 뽑기에서 더 잘 뽑힌다.
- 목표 날짜: 하루나 기간으로 잡는다. 날짜 투표로 같이 갈 날을 맞추고, 캘린더에 넣고, 그날 날씨 예보(16일 안)를 본다.
- 반복: 다녀와도 다시 할 항목.
- 지우면 휴지통에 48시간 남고, 같은 공간 사람 누구나 되살릴 수 있다.

### 5.3 담는 여러 길

- 직접 담기
- 다른 앱에서 '공유 → DoIt2' (링크·글. 지도 앱에서 공유하면 장소까지 채운다)
- AI: 이름만 넣으면 나머지 채우기, 할 것 쪼개기, 문장에서 여러 개 뽑기, 담아 둔 것을 보고 추천
- 공유 코드(6자리)로 다른 사람의 목록 가져오기 (30일 뒤 만료, 하루 50개까지 만들 수 있다)
- 고잇투(여행 일정 앱)에서 공유한 일정 담기, 반대로 장소가 있는 항목으로 고잇투에서 일정 짜기

### 5.4 오늘 뭐 하지? (추천)

- 담아 둔 것 중에 하나를 뽑는다. 직전에 뽑힌 것은 뺀다.
- 비 올 확률이 60% 이상이면 실외를 뺀다.
- 실내만, 실외만, 별점 좋았던 곳 다시 가기 같은 조건.

### 5.5 함께한 기록

- 날짜(하루나 기간), 별점, 한 줄 후기, 비용, 사진.
- 공간에서는 사람마다 따로 평가한다. 사진은 한 사람 5장, 기록 하나에 모두 합쳐 15장.
- 댓글(300자)과 반응 이모지, 사진 하트.
- 공유 카드: 이미지로 저장하거나 카톡·인스타로 보낸다.

### 5.6 추억 모아보기

- 다녀온 곳 지도, 달력, 사진 모음(사람별), 통계(최근 12개월), 지난 이맘때(앞뒤 3일).
- 한 해 돌아보기 카드. 고른 사진(최대 12장)과 함께 웹 링크로 공유할 수 있고 30일 뒤 만료된다. 공개되는 사진은 촬영 위치를 뺀 사본이다.

### 5.7 알림

서버 푸시 (설정에서 묶음마다 끌 수 있다. 꺼도 알림함에는 남는다)

| 묶음                   | 언제                                    |
| ---------------------- | --------------------------------------- |
| 새로 담은 것           | 누가 버킷리스트를 담으면                |
| 기록·평가              | 기록을 남기거나 평가·사진을 더하면      |
| 할 것 체크             | 할 것을 체크하면                        |
| 댓글                   | 댓글이 달리면                           |
| 사진 하트              | 내 사진에 하트를 누르면                 |
| 하고 싶어요·같이 갈 날 | 하고 싶어요를 누르거나 되는 날을 고르면 |

폰 안에서 거는 알림

- 목표 날짜: 일주일 전 오전 10시, 하루 전 오후 8시, 당일 오전 9시 중에 고른다.
- 주말 추천: 금요일 오후 7시에 하나 추천 (끌 수 있다).

### 5.8 홈 화면과 바로가기 (0.3.0)

- 위젯 4개: 1년 전 오늘, 다가오는 날(14일 안), 다음에 할 것(4개), 오늘 뭐 하지(위젯에서 다시 뽑기, 아이폰은 iOS 17 이상).
- 앱 아이콘 길게 누르기: 새로 담기, 오늘 뭐 하지, 일지 보기.
- 앱 아이콘 모양과 색 19가지.

### 5.9 계정

- 익명 계정으로 시작한다. 계정 코드는 서버에 없을 때만 자동으로 만들어 폰에 저장하고, 이미 있으면 그대로 쓴다.
- 앱을 업데이트하다 로그인이 풀려도 폰에 저장된 코드로 같은 계정으로 돌아간다. 네트워크가 끊긴 동안에는 새 계정을 만들지 않는다.
- 기기를 바꿀 때는 계정 되찾기 화면에 코드를 넣는다.
- 계정 삭제: 서버의 내 데이터를 지우고 새 익명 계정으로 시작한다.

### 5.10 도움말과 문의

- 자주 묻는 질문. 답마다 "어디를 누르면 되는지" 단계가 있고, 누르면 그 화면으로 간다.
- 문의하기(1000자, 연락처 100자): 보내면 관리자에게 푸시가 간다. 푸시에는 내용을 넣지 않는다.

## 7. 데이터와 권한

- 서버: Supabase (DB, 로그인, 사진 저장소, Edge Function).
- 모든 표에 RLS를 걸어 공간 멤버만 읽고 쓴다. 여러 표를 바꾸는 일(공간 참여, 공간장 위임 등)은 DB 함수로 묶었다.
- Edge Function: 카카오 검색 프록시, 링크 미리보기, 알림, AI, 계정 코드, 계정 삭제, 문의.
- 개인정보처리방침: https://doit2app.github.io/privacy.html (원본 `site/privacy.html`). 방침이 바뀌면 앱에서 한 번 안내한다.

## 8. 운영

- **관리자 모드**: 관리자 계정에만 설정 제목 줄에 작은 아이콘이 보이고, 6자리 PIN을 넣으면 15분 동안 열린다.
  - 현황: 사용자·공간 수, 최근 활동
  - 받은 문의
  - 로그: 앱 오류(묶음·한 건씩·복사), 많이 쓴 기능(날짜별·최근 기록), AI 호출(비용·최근 호출)
- **오류 기록**: 기기에 먼저 저장했다가 서버로 보낸다. 화면이 터지면 앱을 끄는 대신 다시 시도 화면을 보여준다.
- **업데이트**: 화면 코드는 OTA로 보낸다. 앱 버전이 같은 빌드끼리만 받는다. 새 버전이 준비되면 아래에 "다시 시작" 배너가 뜬다.
- **최소 버전**: 서버의 `app_versions.min_version`보다 낮은 앱은 업데이트하라고 막는다. 지금은 android·ios 모두 0.3.0.
- 출시 절차는 [RELEASE.md](RELEASE.md), 다음 빌드에 넣을 것은 [NEXT_BUILD.md](NEXT_BUILD.md).
