# 다음 스토어 빌드 (0.3.0) 때 넣을 것

OTA로는 못 넣고 새 빌드가 있어야 하는 것들을 여기에 모은다. (2026-11-17 정리)

네이티브 코드가 들어가는 변경은 **빌드를 낼 때까지 main에 합치지 않는다.** main에서 내보내는 OTA는 0.2.0 빌드로 가는데,
새 네이티브 모듈을 쓰는 화면 코드가 섞이면 옛 빌드에서 앱이 죽는다. 빌드 직전에 버전을 0.3.0으로 올리고 합친다.

## 넣기로 한 것

| 기능                  | 내용                                                                                                | 상태                                            |
| --------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| 공유로 담기           | 다른 앱에서 '공유 → DoIt2'로 바로 담기 (링크·글)                                                    | 시작 전                                         |
| 링크로 바로 앱 열기   | 초대·공유 링크를 누르면 웹 페이지 없이 앱이 열림. 앱 설정의 주소 등록 + 소개 사이트의 인증 파일 2개 | 앱 설정·인증 파일 2개 됨. 새 빌드에서 확인 필요 |
| 홈 화면 위젯          | ① 1년 전 오늘 ② 다가오는 날(D-day) ③ 다음에 할 것 목록(누르면 그 항목으로) ④ 오늘 뭐 하지 뽑기      | 시작 전                                         |
| 기기 캘린더에 넣기    | 날짜를 정한 항목을 폰 캘린더 일정으로                                                               | 시작 전                                         |
| 아이콘 꾹 누르기 메뉴 | 새로 담기, 오늘 뭐 하지, 일지 보기                                                                  | 시작 전                                         |
| 앱 아이콘 고르기      | 테마색 6가지 × 밝게/어둡게 = 12개 (`assets/icons/`)                                                 | 그림 준비됨                                     |
| Sentry                | 앱이 통째로 꺼지는 경우까지 오류 수집. 개인정보처리방침에 한 줄 추가 필요                           | 시작 전                                         |

### 위젯에서 정한 것

- '오늘 뭐 하지' 위젯은 위젯 안에서 눌러 다시 뽑는 방식이라 iOS 17 이상에서만 된다.
  그보다 낮은 iOS에서는 위젯 고르는 목록에 **아예 나오지 않게** 한다 (위젯 선언에 `@available(iOS 17.0, *)`).
  나머지 세 위젯은 버전과 상관없이 보인다.
- '다음에 할 것' 위젯의 줄을 누르면 앱의 그 항목 화면으로 간다 (`doit2://item/<id>`).

## 같이 정리할 것

- 새 아이콘·스플래시('하트 두 개' 그림): 집 컴퓨터의 stash에 있다. 넣을지는 그림을 다시 보고 정한다.
- iOS 최소 버전: `0.0.0`으로 낮춰져 있다. 빌드 1을 쓰는 테스터가 없으면 올린다.
- 빌드 뒤: 0.3.0용 OTA를 한 번 내보낸다 (버전이 바뀌면 OTA는 새 빌드로만 간다).

## 미룬 것

- 근처 알림 (백그라운드 위치 권한이 필요해 심사·배터리 부담이 큼)
- 앱 잠금, 별점 요청 (필요해지면)
